# ABDULLAH AHMAD — Motion & Story

Responsive portfolio website for Abdullah Ahmad.

## Contact form
The enquiry form opens the visitor's default email app with the completed project brief addressed to `abdullahahmad7085@gmail.com`. The visitor reviews and sends the email. This static-site approach does not claim delivery until the visitor presses Send. The direct email link is also available as a fallback.
